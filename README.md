# Учебная платформа EduPlatform

Проект представляет собой веб-приложение для подбора лекторов и записи на занятия.

## 🛠 Стек и версии
* **React** (версия 18.2.0) — создание пользовательского интерфейса.
* **Node.js** (версия 18+).
* **CSS3** — стилизация (без использования сторонних библиотек, как требовалось в ТЗ).

## 🚀 Команды для установки и запуска
1. Клонируйте репозиторий:
   `git clone <ссылка_на_твой_репозиторий>`
2. Перейдите в папку проекта:
   `cd edu-platform`
3. Установите зависимости:
   `npm install`
4. Запустите проект в режиме разработки:
   `npm start`
5. Откройте в браузере: `http://localhost:3000`
